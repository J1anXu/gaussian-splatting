# GRAD-DIAG 分析：梯度偏低根因

## 排除的假设

### 1. 随机 Camera 采样差异 → 已排除
两边每个 iteration 使用 **完全相同的 camera**：
```
iter=100: 两边都是 _DSC8716.JPG
iter=200: 两边都是 _DSC8732.JPG
iter=300: 两边都是 _DSC8774.JPG
...全部一致
```

### 2. prefix_T 透射率缩放 → 已排除
iter 100-2500（split 前只有 1 个 block）：
```
prefix_T_mean=1.0000  prefix_T_min=1.0000
```
**透射率为 1.0，梯度没有被缩放，差距在 split 前就存在。**

（split 后 prefix_T 确实降低: blk0 约 0.34, blk1 约 0.73，会进一步拉大差距）

## 实际差异：per-view 梯度对比

同一 camera、同一 iteration 的 grad2d_mean 对比：

| Iter | Camera | Ours grad | Vanilla grad | Ratio |
|------|--------|-----------|-------------|-------|
| 100 | _DSC8716 | 0.00004341* | 0.00006205 | 0.70 |
| 200 | _DSC8732 | 0.00006026* | 0.00009341 | 0.65 |
| 400 | _DSC8841 | 0.00007720* | 0.00010890 | 0.71 |
| 600 | _DSC8699 | 0.00008551* | 0.00010791 | 0.79 |
| 1000 | _DSC8799 | 0.00014264* | 0.00019149 | 0.74 |
| 2000 | _DSC8692 | 0.00005187* | 0.00008301 | 0.62 |

*注: Ours 的 grad 是对所有 n_pts 点取平均（含不可见点 grad=0），vanilla 只对 visible 点取平均。
实际 visible-only 的 ratio 约为 0.85-0.90（见 ACCUM 日志）。

## Loss 对比

| Iter | Ours loss | Vanilla loss | Ours ssim | Vanilla ssim |
|------|----------|-------------|-----------|-------------|
| 100 | 0.5105 | 0.4448 | 0.2278 | 0.3051 |
| 300 | 0.1689 | 0.1680 | 0.4084 | 0.4116 |
| 1000 | 0.1757 | 0.1699 | 0.4322 | 0.4524 |
| 2000 | 0.2354 | 0.1979 | 0.3633 | 0.4022 |

**Ours 的 loss 略高（质量略差），但梯度反而更低。**

SSIM 值显著不同（iter 100: 0.2278 vs 0.3051），说明两边使用了 **不同的 SSIM 实现**。

## 根因锁定：SSIM 实现不同 + 可能的 rasterizer 差异

### SSIM 实现差异
- **Ours**: `fast_ssim()` → `diff_gaussian_rasterization_wenqi_tam._C.fusedssim`
- **Vanilla**: `fused_ssim()` → `fused_ssim_cuda.fusedssim`（来自 submodules/fused-ssim）

这是 **不同的 CUDA kernel**，即使输入相同也会产生不同的 SSIM 值和不同的梯度。

### 调用方式也不同
- Ours: `fast_ssim(img, gt)` → 输入 [3,H,W]
- Vanilla: `fused_ssim(img.unsqueeze(0), gt.unsqueeze(0))` → 输入 [1,3,H,W]

### 影响链条
不同 SSIM → 不同 loss → 不同梯度 → 不同参数更新 → 从 iter 1 开始累积分化

### Rasterizer 差异
- Ours: `diff_gaussian_rasterization_wenqi_tam`（修改版）
- Vanilla: 标准 `diff_gaussian_rasterization`

修改版 rasterizer 的前向/反向传播可能与标准版有细微差异。

## 建议

### 最优先：统一 SSIM 实现
在 ours 的 train.py 中，将 `fast_ssim` 替换为 vanilla 使用的 `fused_ssim`：
```python
from fused_ssim import fused_ssim
ssim_value = fused_ssim(composed_img.unsqueeze(0), gt_image.unsqueeze(0))
```
这可以消除 SSIM 带来的梯度差异。

### 次优先：验证 rasterizer 梯度
用相同参数、相同 camera，分别在两个 rasterizer 上 render + backward，
对比 viewspace_point_tensor.grad 是否一致。
